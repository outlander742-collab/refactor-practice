## Вариант и задание

**Номер варианта:** 7

**Текст задания по варианту:** Исходный код предыдущей работы надо поместить в git-репозиторий.
После этого доработать этот код в соответствии с заданием и добавить изменения в этот же репозиторий.
Задание заключается в улучшении программы работы 1 в части разбиения
исходного кода на более простые функции. Исходный код должен быть отформатирован в соответствии с одним из популярных соглашений о кодировании -
например, соглашении компании Google. Функции программы должны соответствовать принципу SRP. 


## Стиль оформления кода

Код оформлен в соответствии с **Google C++ Style Guide**
(<https://google.github.io/styleguide/cppguide.html>).
Автоматическое форматирование — `.clang-format` с `BasedOnStyle: Google`.

Соблюдены следующие правила:

- отступ 2 пробела, лимит строки 80 символов;
- `CamelCase` для имён функций (`ParseMeasurement`, `Trim`);
- `snake_case` для локальных переменных и параметров (`date_index`);
- header guards в формате `REFACTOR_PRACTICE_<FILE>_H_`;
- порядок директив `#include`: related header → C std → C++ std → прочие
  библиотеки → заголовки проекта;
- все публичные функции снабжены комментариями о назначении, параметрах
  (через `|name|`) и возвращаемом значении;
- параметры, передаваемые по значению только для копирования, помечены
  соответствующим образом; const-корректность соблюдена;
- отсутствуют `using namespace std;` и глобальные переменные.

## Что сделано

1. Исходный код работы №1 помещён в репозиторий (коммит `Initial commit`).
2. Проведён рефакторинг по принципу **SRP** — монолитный `main`
   и класс `PressureMeasurement` (совмещавший данные и парсинг) разбиты
   на модули:
   - `date` — работа с датой;
   - `string_utils` — `Trim` и `SplitByWhitespace`;
   - `number_parser` — парсинг `double` с `,`/`.`;
   - `pressure_measurement` — структура данных и `operator<<`;
   - `measurement_parser` — разбор строки в объект;
   - `main` — только оркестрация сценария.
3. Код отформатирован по Google C++ Style.
4. Все публичные функции снабжены комментариями.
